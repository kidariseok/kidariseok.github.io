# 조약돌(Pebble) 재설계 — 작업 기록

2024 ICISTS × KAIST 해커페어 프로젝트 「조약돌」을 다시 설계하는 작업의 결정 기록입니다.
진행 순서: Analyze → Challenge → Ask → Lo-fi → **승인 대기** → Phase 1~10

## 현재 상태

- 단계: Lo-fi v0.1 승인 대기 (승인 전에는 Hi-fi, 디자인 시스템, 코드 작업 없음)
- Lo-fi 문서: https://claude.ai/artifact/BvfkDm5wDPbJvyHtnt2roR (비공개)

## 진단 요약 (1단계)

- 2024년 기획 문서의 출근 '질문'(내 생각 답하기 → 저녁에 다른 사람의 답 짐작하기)이 최종 UI에서 '상식 퀴즈'(1963년 라면 가격)로 바뀌면서 핵심 메커니즘이 사라졌다.
- 선물하기는 Quiz → Points → Gift 구조에 머물렀다. 이해와 관심을 거치는 고리가 없었다.
- After Journey Map은 Before의 장면(Jennifer와 Lucy의 업무 검토)으로 돌아가지 않았다. 앱 사용과 관계 변화 사이를 잇는 인과의 다리가 없었다.
- 세대 라벨(M/X/Z 탭, 세대별 정답률 일반화)은 2024 멘토링에서 받은 '낙인 효과 기피' 조언과 충돌했다.

## Lo-fi v0.1에서 제안한 가정 (승인 시 확인)

- MZ·X세대 같은 라벨은 쓰지 않는다. 연령대와 연차는 5명 이상 모인 집계를 볼 때만 렌즈로 쓴다.
- 실물 선물은 뺀다. 건네는 것은 이름과 이유가 붙은 조약돌 하나다.
- HR 웹 콘솔은 이후 단계로 미룬다.
- 리듬: 매일 질문 1개(09:10) → 결과(17:30) → 주 1회 10분 팀 대화.

- 개발: `ponytail` 스킬을 사용한다. 높은 품질의 코드를 필요한 양만큼만 작성한다.
- 2026.10.02 기준 두 스킬 모두 이 세션에 설치되어 있지 않다. 구현 단계 전에 활성화해야 한다.
