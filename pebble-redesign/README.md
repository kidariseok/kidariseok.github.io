# 조약돌(Pebble) 재설계 — 작업 기록

2024 ICISTS × KAIST 해커페어 프로젝트 「조약돌」을 다시 설계하는 작업의 결정 기록입니다.
진행 순서: Analyze → Challenge → Ask → Lo-fi → **승인 대기** → Phase 1~10

## 현재 상태

- 단계: Lo-fi v0.3 승인 대기 (승인 전에는 Hi-fi, 디자인 시스템, 코드 작업 없음)
- Lo-fi 문서: https://claude.ai/artifact/BvfkDm5wDPbJvyHtnt2roR (비공개, Version 3 = v0.3, Version 2 = v0.2, Version 1 = v0.1)

## 진단 요약 (1단계)

- 2024년 기획 문서의 출근 '질문'(내 생각 답하기 → 저녁에 다른 사람의 답 짐작하기)이 최종 UI에서 '상식 퀴즈'(1963년 라면 가격)로 바뀌면서 핵심 메커니즘이 사라졌다.
- 선물하기는 Quiz → Points → Gift 구조에 머물렀다. 이해와 관심을 거치는 고리가 없었다.
- After Journey Map은 Before의 장면(Jennifer와 Lucy의 업무 검토)으로 돌아가지 않았다. 앱 사용과 관계 변화 사이를 잇는 인과의 다리가 없었다.
- 세대 라벨(M/X/Z 탭, 세대별 정답률 일반화)은 2024 멘토링에서 받은 '낙인 효과 기피' 조언과 충돌했다.

| 항목 | 결정 |
|---|---|
| 종착점 | 포트폴리오 컨셉 + 웹 인터랙티브 프로토타입 (Claude와 함께 구현) |

| 질문 콘텐츠 | 짧은 질문 + 4지선다 형식은 유지하고, 정답 없는 의견·경험 질문으로 새로 구성 |

## (폐기) Lo-fi v0.1에서 제안한 가정

2026.10.03 사용자 지시로 방향 C(팀 대화, 공든 탑)를 내려놓았다. 아래는 기록용.

- MZ·X세대 같은 라벨은 쓰지 않는다. 연령대와 연차는 5명 이상 모인 집계를 볼 때만 렌즈로 쓴다.
- 실물 선물은 뺀다. 건네는 것은 이름과 이유가 붙은 조약돌 하나다.
- HR 웹 콘솔은 이후 단계로 미룬다.
- 리듬: 매일 질문 1개(09:10) → 결과(17:30) → 주 1회 10분 팀 대화.

## 재정렬 (2026.10.03)

- v0.1이 조직문화 개입 서비스처럼 무거워졌다. 팀 대화, 팀 약속, 공든 탑, HR 콘솔, 심리적 안전감 측정, 팀 단위 개입을 삭제했다.
- 새 핵심: 서로 잘 모르는 회사 사람들이 작은 질문과 조약돌을 매개로 서로를 조금씩 궁금해하게 만들고, 대화가 시작될 작은 계기를 준다. 그다음은 사용자의 선택이다.
- 원칙: 기능을 더하지 않고 계속 묻는다. 정말 필요한가, 부담을 주지 않는가, 핵심 경험을 강화하는가, 가벼움을 해치지 않는가.

| 항목 | 결정 |
|---|---|
| 답 | 완전 익명 |
| 리듬 | 출퇴근 등록할 때 함께 푼다. 출근 질문 → 퇴근 때 결과, 퇴근 질문 → 다음 날 출근 때 결과. 주말 없음 |
| 조약돌 | 질문 하나 = 하나. 10개 = 작은 탑(제안). 탑을 커피·간식 하나로 바꿔 한 사람에게 건넴 |
| 메시지 | 짧은 문장 고르기 + 직접 쓰기. 받은 사람은 짧게 화답 가능. 돌려주기 없음 |
| 주인공 | 서로 다른 부서의 잘 모르는 두 사람 (재무팀 Lucy, 마케팅팀 Julie) |
| 구조 | 탭 두 개: 오늘(등록, 결과, 질문) / 조약돌(쌓기, 건네기, 받은·건넨 조약돌) |

## v0.3 결정 (2026.10.03)

| 항목 | 결정 |
|---|---|
| 탑 | 조약돌 10개 = 탑 하나 = 2,000원만큼. 보유 탑을 여러 개 모을 수 있음 |
| 스토어 | 상품마다 탑 개수로 가격. 탑 개수 = 결제 금액 ÷ 2,000원 |
| 사내 카페 | 정가의 반값 (대화의 장이 되므로). 예: 4,000원 → 2,000원 = 탑 1개 |
| 모바일 쿠폰 | 정가 그대로. 예: 4,000원 = 탑 2개 |
| 비용 | 회사 복지 예산 |
| 관문 | 질문에 답해야 '출근 완료'. 출근 시각은 버튼을 누른 순간으로 기록해 근태 누락 방지 |
| 마감 | 없음. 결과는 다음 등록 때 그때까지 모인 답으로 (10명 미만이면 다음으로 미룸) |
| 차단 설정 | 넣지 않음 |

v0.3 확인 대기: 나누어떨어지지 않는 가격은 올림(4,500원 → 탑 3개), 받는 사람에게 가격·탑 개수 숨기기.
