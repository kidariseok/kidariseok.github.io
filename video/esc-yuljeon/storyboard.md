# ESC_ 지금 우리 율전은 — 게임 소개 영상 스토리보드 (v4, 1:25 압축판)

> v3 변경: 포트폴리오 요소(출발점, 역할, 결과)를 모두 빼고 **"어떤 게임인지"를 보여주는 게임 트레일러**로 다시 짰습니다. 스토리로 바로 시작하고, 타이틀이 나온 뒤 세계관 → 게임 방식 → 스테이지별 플레이 → 엔딩 순서로 이어집니다. 규칙 설명과 플레이 장면을 따로 두지 않고, 실제 플레이 화면에 STEP 표시를 붙여 규칙이 함께 보이게 했습니다.

- 규격: 1920×1080 · 30fps · MP4(H.264 + AAC) · **1:25** (v3 승인본 2:00에서 압축)
- 톤: 레트로 게임 트레일러. 게임의 픽셀아트, 나무 팻말 UI, 갈색·보라 동굴과 하늘·잔디 색을 그대로 사용
- 소리: 자막 + **직접 합성한 8비트 칩튠 BGM과 효과음** (내레이션 없음)
- 자막: 하단 고정, 픽셀 폰트 Galmuri11 Bold 48px, 한 번에 최대 두 줄, 줄당 약 20자 이하
- 전환: 기본은 컷. 픽셀 모자이크 디졸브는 파트가 바뀔 때만 사용
- 패러디 캐릭터: 교수님 NPC는 사용, **최강록(퀴즈 4 벤젠고리관)은 제외** — 스테이지 4는 보상 아이템 화면만 사용
- 장면별 텍스트와 타이밍은 제작 단계에서 `scenes.js` 한 파일로 관리합니다

## 제작 방식

- **HTML + Playwright + ffmpeg**: 장면을 HTML/CSS로 만들고, 시간 t를 넣으면 그 순간의 화면이 정해지도록 짠 뒤 3,600프레임을 캡처해서 ffmpeg로 인코딩합니다. Remotion은 렌더러가 브라우저를 따로 내려받아야 하는데 이 환경에서는 막혀 있어서, 같은 방식을 직접 구현합니다.
- 그림 소스: Figma MCP로 레이어를 2–4배 해상도의 투명 PNG로 받아 픽셀아트가 선명하게 나오게 합니다.
- 폰트: Galmuri11 / Galmuri11 Bold (SIL OFL 1.1, npm `galmuri`)
- BGM·효과음: Python으로 사각파·삼각파·노이즈를 직접 합성한 칩튠입니다. 외부 음원은 쓰지 않습니다.
