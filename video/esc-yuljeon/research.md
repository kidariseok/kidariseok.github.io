## 4. 게임 규칙 · 진행 흐름 [확인] (메인/퀴즈 플로우 차트 `753:1572`, `753:1622`)

1. **로그인**: 닉네임(최대 6글자) + 전화번호(경품 추첨용, 사용 후 파기)
2. **캐릭터 선택**: 명웅이 / 율웅이 → "좋아.! '미르미' 이제 율전을 구하러 가보자!!"
3. **프롤로그** 시청 → 교수님이 "행사구역 내에서 QR코드를 찾아보게나!" (지도 제공)
4. **QR 찾기**: 행사장 곳곳의 QR 스캔 → "코인을 획득하였습니다!" (이미 쓴 QR이면 "이미 지급된 코인입니다")
5. **퀴즈**: 스토리 대사 → 문제(객관식/단답식) → 오답이면 힌트 → 정답이면 아이템 획득·장착 → "풀이한 문제 n/5" → 메인으로
6. 메인 화면은 진행도에 따라 달라짐: 스테이지 0(밝은 배경) → 1–6(어두운 배경·감염된 원숭이·어두운 BGM) → 7(엔딩, 폭죽·춤)
7. **최종 미션**: "율전을 점령하려는 버그 원숭이를 처치하고 영웅이 되어주세요!" — 무작위로 움직이는 버그 원숭이 터치 (귀여운 원숭이는 공격 금지) → GAME CLEAR / GAME OVER
8. **엔딩**: 다시 평화로워진 율전 → **용사 인증서**(닉네임·클리어 시간·랭킹, 공유하기) → 인스타 스토리 인증 이벤트(@9oormthonuniv.skku) → LET's PARTY → 엔딩 크레딧
9. **실시간 랭킹**: 닉네임 / 스테이지 / 시간

- [확인 필요] QR 코인과 퀴즈 입장의 관계 (코인 1개 = 퀴즈 1개 해금인지)
