## 3. 저장소 규칙과의 관계

- CLAUDE.md 9(메인 문구) · 10(화면이 달라지는 CSS): 이번 작업은 작성자가 **"포트폴리오 전체 개선"을 요청**했고 브리프가 메인 카드 · 상세 구조 변경을 명시했으므로 적용함. 단, 별도 브랜치에서만 커밋하고 `main` 배포는 작성자 확인 뒤로.
- 새 데이터 키(`glance` · `card.what` · `*Label` · `panel.budget`)와 소제목 속성(`fold`)은 블록 종류를 늘리지 않는 '선택 속성'으로 추가하고, `tools/check-content.mjs` · 문서에 규칙을 함께 넣음.
- 사실이 필요한 제안은 하나도 사이트에 넣지 않음. 4장의 질문 목록으로 작성자에게 넘김.
