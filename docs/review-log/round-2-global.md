## 4. 포워딩 판단

- **APAC PM · 서비스 기획 인턴 풀: 포워딩 (조건 없음).** round 1 에 넘기기 전에 고치길 바랐던 세 가지(휴대폰 Projects 카드, ESC 문장 충돌, 접힌 핵심 문장)가 모두 풀렸습니다. 6개 첫 화면 모두 문제 → 판단(또는 정직한 대체 라벨) → 결과와 한계가 보이고, EN 에 서로 부딪히는 문장이 없습니다.
- **AI PM 인턴: 포워딩, 단 메모 첨부.** 이번에 2GATHER 04절에서 '플랫폼 규칙은 본인이 조사해 정리 → 그 위에서 gpt-4o-mini 가 타임라인 · 예산을 JSON 으로 생성(팀 구현)'이 보이게 되어 AI 서비스를 기획한 근거는 생겼습니다. 다만 AI 출력을 어떻게 검증 · 평가했는지, 모델과 규칙의 역할을 누가 어떻게 나눴는지는 아직 페이지에 없습니다(R0-17, 4장 2번). 메모: "AI 쪽 본인 판단 범위와 출력 검증 방식은 첫 통화에서 확인".
- **첫 통화 질문**: ① 인턴 가능 시기와 졸업 예정(4장 6번) ② '채널 대신 형식 순위' 는 본인 제안이었는지(4장 12번) ③ gpt-4o-mini 결과가 맞는지 어떻게 확인했고, 실제로 어떤 결과가 틀렸는지(4장 2번).
