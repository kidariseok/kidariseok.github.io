# 본문 블록 (ko · en 같은 순서 · 같은 종류로)

`body` 배열에 아래 모양의 객체를 순서대로 넣는다. 글자 안에서는 `<b>` 와 `<br>` 만 쓴다. 한 블록 = 키 하나.

| 블록 | 모양 | 쓰임 |
| --- | --- | --- |
| h | `{"k":"01 · 이름","h":"문장형 제목.","toc":"목차 이름(16자·영어 24자 이하, 선택)"}` | 소제목. 유형 A·B 는 **모든 h 에 k**(마지막도 `{"k":"05 · 돌아보며","h":"문장."}` / `Looking back`), 유형 C 는 k 없이 `{"h":"명사형"}` 1–2개(마지막 `돌아보며`). **h 가 3개 이상이면 목차 자동 생성** |
| p | `{"p":"문장"}` | 문단 |
| lead | `{"lead":"한두 문장"}` | 맨 앞 굵은 도입 |
| q | `{"q":"인용 · 핵심 한 줄"}` | 파란 줄 인용 |
| h3 | `{"h3":"작은 제목"}` | 소제목 안의 구분 |
| ul | `{"ul":["항목","항목"]}` | 점 목록 |
| checks | `{"checks":["항목","항목"]}` | 체크 목록 |
| facts | `{"facts":["짧은 칩","짧은 칩"]}` | 알약 칩 (짧게) |
| flow | `{"flow":["단계","단계"]}` | 화살표로 이어지는 단계 |
| stat | `{"stat":[{"k":"라벨","v":"값","hi":true}]}` | 숫자 상자 (3개까지, hi=강조 1개) |
| boxes | `{"boxes":["문장","문장"]}` | 문제 상자 |
| cards | `{"cards":[{"n":"01","t":"제목","d":"설명"}]}` | 카드 **2–4장**씩 (6장이면 3+3 두 블록) |
| cmp | `{"cmp":[{"n":"A","t":"제목","d":"설명"},{"n":"B","t":"제목","d":"설명"}]}` | 정확히 2칸 비교 |
| people | `{"people":[{"role":"역할","n":1,"me":true,"note":"나"}],"note":"각주(선택)"}` | 팀 구성. 팀원 **이름은 쓰지 않고** 역할·인원수만 |
| roles | `{"roles":{"tl":"TEAM","ml":"MY CONTRIBUTION","team":["…"],"mine":["…"]}}` | 팀 일 / 내 일 |
| note | `{"note":"<b>제목</b><br>· 내용"}` | 보충 상자 |
| link | `{"link":"글자","href":"https://…"}` | 바깥 링크 버튼 (사이트 안은 `#a/활동id`) |
| cert | `{"cert":{"img":"파일명","alt":"설명","cap":"캡션"}}` | 이수증 사진 (img/ 에 있어야 함) |
| files | (봉사 내역 전용. 쓰지 않는다) | |

**panel**: `role`(필수) `team` `scale` `period`(날짜는 자동이라 보통 생략) `where` `result` `key` `links:[{"t":"글자","href":"…"}]`. 칸이 3개 이상 나오게 쓴다. 프로젝트(유형 A)는 `panel` 대신 `proj` 를 쓸 수 있다 (docs/CONTENT_GUIDELINES.md 4장).
**card**(메인 대표 활동 카드)는 요청이 있을 때만.
**쓰지 않는 것**: 사실 · 숫자를 지어내지 않는다 (모르면 `[확인 필요] …` 로 적고 보고). 팀원 실명 · 다른 사람 얼굴 · 주소는 넣지 않는다.
